# Installing this skill in Claude (no terminal required)

This is the easiest way to install this skill — no terminal, no copying
files into hidden folders. Claude's web app has a built-in uploader for
exactly this.

## Steps

1. Download **`hubspot-deal-pipeline-report.zip`** from this folder (click
   it on GitHub, then the "Download raw file" / download icon).
2. Go to **claude.ai** and log in.
3. Click **Customize**, then **Skills**.
4. Click the **+** button, then **"+ Create skill"**.
5. Choose **"Upload a skill"**.
6. Select the zip file you downloaded in step 1.

That's it — the skill is installed. Start a conversation and ask for a
"HubSpot deal pipeline report" to use it.

## What happens next

The first time you use it, it'll walk you through connecting to HubSpot
(either creating a private app + token, or using an already-connected
HubSpot account, whichever you prefer — it'll explain both and ask). See
the main [README](../README.md) for what those two options mean if you
want to read ahead.

## If the upload doesn't work

Claude's skill upload feature is relatively new and its exact requirements
may change. If the upload is rejected or behaves unexpectedly:
- Make sure you're uploading the `.zip` file itself, not the unzipped
  folder.
- Check **Customize → Skills** for a specific error message — it usually
  says what's wrong (e.g. a naming issue).
- As a fallback, technical users can install it manually — see the
  ["Install the skill"](../README.md#3-install-the-skill) section of the
  main README for the copy-into-a-folder method instead.
